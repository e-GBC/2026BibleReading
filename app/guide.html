一、這麼多讀經工具，要用哪個好？

1. Which tool should I use?

感謝主，在提出年度讀經計劃後，會友們熱烈響應，也持續提出建議，讓教牧行政團隊能持續更新改進，預備合適的工具給不同需求的使用者。

紙本版：適合不使用3C裝置者
試算表：已有讀經工具，且擅長使用網頁登錄記錄
APP版：綜合需求，適合後來加入，仍可追上進度

您仍可繼續使用您已經習慣的版本。
若是新加入讀經計畫的弟兄姊妹，歡迎優先使用APP版。

Thank the Lord for the enthusiastic response. Our team continues to improve tools for different needs.

Paper: For non-tech users.
Spreadsheet: For those who enjoy web logging.
APP: Recommended for new joiners to catch up.

You can continue to use the version you are used to.
If you are a new member of the Bible Reading Plan, you are welcome to use the APP version first.

二、檔案不見了？什麼是安裝應用程式？

2. Progress gone? What is Install App?

此次製作的APP版本為網頁應用程式。

若使用Line啟用網頁，即可能發生記錄遺失的問題；
安裝應用程式則可以確保資料存檔於裝置瀏覽器記憶體中。

您可以點擊下方按鈕進行應用程式安裝。安裝成功後，會在您的桌面新增一個捷徑，作為未來懷恩堂數位事工的平台入口。

三、工具使用說明？快速追回進度？

3. Features & Catching Up

讀經工具功能包含：

每日讀經：中英文、AI語音讀經，文字放大
追回進度：完成單月進度、完成今天以前所有進度
進度總覽：以動畫模式看到整體進度

Features include:

Daily Reading: Bilingual, AI Voice, Text Resizing.
Catch Up: Finish month or all past items instantly.
Summary: View progress with animations.

四、如何同步進度到其他裝置？

4. Syncing to Other Devices

點擊工具中的「匯出備份」，會產生一段專屬代碼檔案。在新裝置上點擊「匯入備份」並選擇該檔案即可同步。

Use "Export Archive" to get a file/code, then "Import Archive" on your new device.

五、如何更新APP？

5. How to Update?

未來若教會公告需要使用者更新APP，使用者可使用「工具設定」下的「手動更新」，即可連線更新至最新版本資料。更新後可比對工具設定下方的版本編號是否正確。

Use "Force Update" in Tools settings when maintenance is announced. Check version at the footer.
